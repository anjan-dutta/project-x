What's set up

Zero build step

Plain HTML and CSS in one file. No bundler, no dependencies, nothing to install.

Deploys on push

A GitHub Actions workflow publishes every commit to main automatically.

Light and dark

The palette follows the reader's system theme through prefers-color-scheme.

Making it yours

  1. Replace this copy. Everything visible lives in index.html.
  2. Add pages as sibling files: about.html is reachable at /about.html.
  3. Bring a framework later by pointing the workflow's upload step at your build output directory instead of the repository root.
  4. Use a custom domain from Settings → Pages, which writes a CNAME file for you.
